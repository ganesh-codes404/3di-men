builder

A local Qwen3-4B model (llama.cpp, in-process, no network) breaks your prompt into independently-buildable parts, asking clarifying questions first if needed. Each part is built in parallel by 3di-men's own proprietary tool-composing model — the LLM never touches geometry, only language. This runs entirely on-device with no GPU, so each step can take 8–15 minutes — the elapsed timer below is live, not stuck.
